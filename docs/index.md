# 数据科学与数字人文

> 一本"可复现、案例真实、伦理在场"的数字教材。本站点由 **MkDocs + Material** 构建，逐模块上线。

## 怎样使用本教材

- **可复现**：每个模块的代码片段都可在统一预部署环境中一键运行；数据、环境、步骤公开。
- **案例真实**：数据集与文献均来自真实来源，不拿玩具数据粉饰结论。
- **伦理在场**：每模块设"伦理红线"与标注要求，方法再炫也先过伦理这一关。
