## 模块九　知识图谱与语义技术






> **学习目标**：完成本模块后，你应能（1）说出 RDF、URI、本体各自解决什么问题；（2）描述从实体抽取到图谱对齐的构建流程；（3）用 GraphRAG 让问答"有据可依"；（4）指出本体设计本身可能固化的世界观偏见。

### 9.1 把零散事实连成网络

模块六的关系网是"图"，知识图谱是"带语义的图"：边不仅有"连"，还有"是""位于""师从"这样的**含义**。于是机器不仅能说"甲连乙"，还能推理"甲的学生乙，也师从丙"。

### 9.2 语义网三件套：URI、RDF 与本体

- **URI**：给每个实体一个全网唯一ID（如 `:苏轼`），避免"苏轼/苏东坡"被当成两人；
- **RDF**：用"主—谓—宾"三元组表达事实（苏轼—字号—东坡居士）；
- **本体（ontology）**：规定"类"与"关系"的词典（人可以有"师从"关系，地点可以有"位于"关系）。

本模块 V2.1 的 *Using the Semantic Web in digital humanities*、*Sampo model and portal series* 展示了语义网如何在人文中落地。

### 9.3 本体设计：类、属性与关系

设计本体就是"定义你的世界由什么组成"。例如"诗人"类有属性"生年/籍贯/师承"；"作品"类有"体裁/年代"。本体定得好，检索与推理才稳；定得窄，就装不下真实历史的复杂。

### 9.4 图谱构建：从抽取到对齐

流程通常是：① 用 NER（模块四）抽实体；② 用关系抽取连边；③ **对齐**——把不同来源的"苏轼"归为同一节点，避免重复；④ 补属性。本模块 V2.1 的 *ChronoGrapher*（事件为中心构建）、*Geographic Knowledge Graph Summarization* 是两条技术路线。

### 9.5 GraphRAG：图谱增强问答

**GraphRAG** 把知识图谱接到大模型：提问时先查图谱取相关子图，再让模型基于"有据"的片段回答，显著降低幻觉。这对人文特别有用——让 LLM 只基于你编好的领域事实说话，而非凭空编。

### 9.6 伦理坐标：本体即世界观（本模块核心能力）

- **分类的暴力**：用今天的类去切历史身份（如强行把古人归入现代学科），会扭曲；
- **被固化**：本体一旦写成，就默认"世界就该这么分"，边缘类别被排除；
- **来源偏见**：图谱只含被数字化的实体，沉默者再次缺席。

> **一条红线**：不把本体当成"客观真理"，而是标明"这是本研究采用的分类视角"；对历史身份保持谦卑。

### 9.7 第一次动手：建一张小领域图谱并问答

> **小练习 9.1（知识图谱）**：取一个你熟悉的小领域（如某学派师承、某类器物出土地），手工或借助 NER 抽出 10–20 个实体与关系，写成三元组，用 `rdflib` 建图并回答一个问题（如"苏轼的师承链是谁"）。本模块 V2.2 的《文化基因视域下诗词资源多维知识重组与可视化研究》《吐蕃藏文金石铭刻知识图谱构建研究》《基于知识图谱的井冈山革命文化资源数字叙事模型的构建与实现》分别是诗词、民族文献、红色资源的图谱范例，可对照你图谱的"叙事"设计。


### 9.8 第二次动手：用 GraphRAG 在自有语料上问答并核查证据
- **目标**：在 9.7 小图谱基础上，接 GraphRAG，验证“答案能否回溯到原文”。
- **步骤**：
  1. 准备一份小语料（如某位学者的论文集）；
  2. 构建图谱 + 向量索引；
  3. 提 5 个问题；
  4. 对每答标注“证据句”；
  5. 统计可回溯比例，写反思。
- **工具**：GraphRAG 或轻量 LangGraph 方案。
- **产出**：问答记录 + 证据回溯表 + 反思。
- **评价量规**：流程可跑（30%）、证据标注（30%）、回溯分析（40%）。
### 9.9 本章小结

带走三件事：**语义网三件套**（URI/RDF/本体）、**构建四步**（抽取→连边→对齐→补属性）、**GraphRAG 降幻觉 + 本体偏见自觉**。图谱让人文事实"可推理"，但分类视角要坦白。

### 9.10 思考题

1. 给你的小领域设计本体时，哪一类事实最难归类？这反映了什么分类难题？
2. 知识图谱"对齐"把不同来源的同一实体合并，会不会因此丢失差异（如不同文献对同人的不同记载）？
3. 用现代学科框架给古人分类，可能怎样扭曲历史？如何在本体里留"弹性"？



### 9.11 思政融入（课程思政）

> **思政融入（课程思政）**：构建基于中华典籍、方志、民族文献的知识图谱，是在为**中国自主知识体系**夯实地基。当我们用自己的材料、自己的分类去组织人类经验，就不再被动沿用他人框架。自主的本体与图谱，是文化主体性的数字表达——把中国人的知识家园掌握在自己手里。

> **思政案例（课程思政示范案例 / AI 思政课 知识库）**：可参照人工智能思政精准教学中“知识图谱”的应用——自主构建领域图谱，正服务于中国自主知识体系建设。

```python
import urllib.request, urllib.parse, json
q = 'data science digital humanities'
url = 'https://api.openalex.org/works?search=' + urllib.parse.quote(q) + '&per_page=10&sort=cited_by_count:desc'
oa = json.loads(urllib.request.urlopen(url, timeout=30).read())
for w in oa['results']:
    print(w['publication_year'], w['title'], '->', (w.get('primary_location') or {}).get('source', {}).get('display_name'))
```
