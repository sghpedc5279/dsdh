## 模块一　导论：当数据科学遇见数字人文

> **学习目标**：完成本模块后，你应能（1）说清"数据科学"与"数字人文"各自是什么、为何相遇；（2）复述本书"可复现、案例真实、伦理在场"的方法论承诺；（3）建立属于自己的"伦理坐标"，在动手之前先能提出三个关键问题；（4）独立完成第一次可复现检索——复现一篇数字人文文献。
### 1.0 课程思政融入

> **思政导入**：数据科学是当今大国科技竞争的焦点之一。当我们用计算方法研究中华典籍、文物与历史，本质上是在**用自主的方法守护与阐释中华文脉**——把论文写在祖国大地上。愿你在本课程中，既习得“规模与严谨”，也始终记得它的国家与文化意义：让沉淀千年的文明，在数字时代被看见、被理解、被传承。

> **思政案例**：施一公《人工智能时代，教育何为》（人民日报）“落实立德树人”的论断——方法之上，育人为本。
### 1.1 为什么要开这门课：一个被数据重塑的人文学

人文学从来离不开"材料"。从竹简、写本到印刷书，每一次媒介变革都在改变学者"读什么、怎么读"。今天，人文材料正在经历又一次转型：**从纸上的文本，变成可计算的数据**——古籍被扫描与 OCR、报刊被全文入库、档案被数字化、口述史被录音转写、艺术品被高分辨率成像、城市被传感器与地图持续记录。

与此同时，数据科学在最近二十年迅速成熟：自然语言处理能处理中文分词与句法，计算机视觉能辨认碑帖与器物，知识图谱能把零散的人、地、时、事连成网络，机器学习能从海量语料中找出人眼难及的模式。这些方法，恰好为"怎么从大规模人文材料中提问"提供了底座。

于是两个方向相向而行，催生了一门新课：**用数据科学的方法研究人文问题，并用人文学的尺度反思这些方法本身**。这门课的目标，不是把人文学者训练成算法工程师，而是让每一位人文背景的学习者，都能亲手把"一个好问题"变成"一段可复现的分析"——并在此过程中，始终保持对人、对社群、对历史的尊重。

### 1.2 两个主角：数据科学是什么，数字人文是什么

**数据科学**，我们把它定义为一种以数据为原料、以计算为方法、以可复现为纪律的探究范式。它通常沿着一条流水线展开：

> 采集 → 清洗 → 建模 → 验证 → 沟通

这条流水线看似中性，却处处藏着选择：采集什么、丢弃什么、用什么指标衡量"好"、把结果讲给谁听。数据科学的可贵之处，正在于它要求这些选择**可见、可质疑、可复现**。

**数字人文**，常被误解为"文科加电脑"。更准确地说，它是**用数字方法研究人文对象，并持续反思方法本身的人文学分支**。它不满足于"把书扫进电脑"，而要追问：数字化之后，我们能否提出此前无法提出的问题？算法的分类，是否会悄悄替历史做主？所谓"客观的计算结果"，背后站着谁的世界观？

这段历史不算短。早在 1949 年，Roberto Busa 神父便与 IBM 合作，为托马斯·阿奎那的著作构建词汇索引（Index Thomisticus），被视为计算人文的早期实践；此后从"人文计算"（humanities computing）到今天的"数字人文"（digital humanities），核心始终没变：**方法服务于问题，而不是相反**。

### 1.3 当数据科学遇见数字人文：三种相遇方式

数据科学与数字人文的融合并非简单的技术叠加，而是双向适配、互相重塑的深度耦合。二者的相遇至少呈现三种核心姿态，区别于单一的技术套用或人文思辨，本书后续模块将结合实操与理论逐一展开，结合经典学术案例补充阐释如下：

一、方法下沉：通用计算技术落地大体量人文材料（技术赋能人文）
方法下沉是数据科学与数字人文最基础、最直观的融合形态，核心是将成熟、标准化的数据科学、人工智能技术，直接迁移应用于海量、非结构化的人文遗存与文献材料，实现传统人文研究“肉眼精读、小样本考证”向“机器全域扫描、大样本统计”的突破，解决传统研究无法处理大体量资料的痛点。
典型落地案例：
1. NLP主题模型赋能近代报刊研究：学界依托LDA、BERT等成熟主题模型，对晚清至民国上千万份《申报》《大公报》等近代报刊语料进行批量分析。传统学者穷尽数年时间，也只能精读数百份报刊、梳理局部舆论脉络；而通过标准化主题建模技术，可自动抓取报刊核心议题、统计关键词热度、梳理舆论流变轨迹，精准还原近代社会思潮、民生议题、外交观念的百年演变规律，实现宏观社会文化史的量化研究。
2. 计算机视觉OCR技术活化碑帖文物：传统碑刻、摩崖、墓志研究，依赖人工拓片、手写誊录、逐字校对，不仅效率极低，还易出现人工誊录误差，且大量残损、模糊的古碑文字难以辨识。通用OCR、图像超分辨率修复、文字检测技术落地后，可批量对海量碑帖拓片、石刻影像进行数字化识别，将图像化的文物文字转化为可检索、可统计、可比对的结构化文本。同时结合图像降噪技术修复残损文字，让散落在各地的古代碑刻文献实现全域数字化归档与文本复用。
3. 知识图谱快速梳理人文谱系：依托通用知识图谱构建技术，对二十四史、历代方志、文人别集等海量古籍文献进行实体抽取，自动识别人物、地名、官职、事件、时间等核心要素，快速搭建历史人物谱系、古代地理沿革图谱、重大历史事件关联网络，替代传统人工梳理史料、考证人物关系的繁琐工作。
该模式的核心特征是技术为主、人文适配，通用算法无需大幅改造，直接服务于人文材料的数字化、量化加工，是数字人文入门级、普及度最高的融合形态。
二、问题牵引：人文真问题反向改造计算方法（人文重塑技术）
方法下沉是“技术套用人文”，而问题牵引是“人文倒逼技术迭代”。人文材料独有的复杂性、特殊性，使得标准化的通用数据算法、NLP模型无法直接适配，真实的人文研究问题不断倒逼计算方法本土化、定制化、精细化改造，让技术从“通用工具”变成“人文专属研究工具”，实现技术的二次创新与适配升级。
典型落地案例：
1. 古籍文本特征倒逼NLP模型本土化改造：现代通用NLP模型适配的是现代汉语、规范简体文本，而中文古籍存在无句读、无标点、异体字泛滥、帝王避讳字、通假字、古今字混用等独有特征。通用分词、词性标注模型对古籍文本识别准确率极低，无法直接使用。为此学界针对性改造算法，训练专属古籍分词模型、异体字归一化算法、避讳字自动识别还原模型，打破通用NLP的适配局限，让人工智能真正适配古籍整理、文献校勘、古籍断代的核心研究场景。
2. 口述史方言口语倒逼标注与转录流程重构：现代语音识别、文本标注模型适配标准普通话、书面化文本，而民间口述史、非遗口述资料、地方民俗访谈存在大量方言俚语、口语赘余、语序混乱、口头歧义、无规范文字等问题。通用语音转写工具误差率极高，无法满足人文研究的严谨性要求。基于口述史研究的真实需求，学界重新设计音频降噪、方言语音适配、口语文本清洗、人文语义标注的全流程体系，定制口述史专属的转录校对算法，解决海量口述资料难以数字化归档与分析的行业难题。
3. 古典诗词格律问题倒逼文本计算模型优化：通用文本相似度、语义匹配模型无法识别古诗词平仄、押韵、对仗、格律规则。为实现古典诗词的量化研究、风格溯源、作者辨伪，研究者基于诗词研究的专业问题，改造文本计算算法，新增格律特征提取、韵脚识别、平仄校验模块，让数据技术适配古典文学的专属研究范式。
该模式的核心特征是人文问题为核心，技术为载体，方法不再是简单套用，而是被人文研究的特殊性打磨、重构，实现技术与人文场景的深度适配。
三、反思升维：人文批判视角约束计算伦理（人文超越技术）
无论是方法下沉还是问题牵引，都聚焦于“技术如何服务人文研究”，而反思升维是数字人文的高阶融合形态。数据科学追求效率、量化、标准化，天然存在技术偏见与逻辑局限，而人文学的批判思维、伦理视角、人文温度，能够约束技术的工具理性，规避量化研究的弊端，让数字人文研究守住人文本质，避免“技术至上、唯数据论”的研究误区。算法偏见、样本偏差、可解释性缺失、人文价值消解，从来不是单纯的技术细节，而是数字人文必须直面的核心学术与伦理问题。
典型落地案例：
1. 样本代表性批判，规避量化研究偏差：诸多近代文学、社会史量化研究，仅依托公开数字化报刊、馆藏文献开展数据分析，忽略了民间未归档手稿、小众刊物、底层民众文献等缺失样本。数据模型基于片面样本得出的“社会思潮统一趋势”“文学风格整体特征”等结论，存在严重学术偏差。人文批判视角介入后，研究者不再盲从数据结果，而是主动辨析样本局限性，修正量化结论，兼顾数据规律与人文多元性、复杂性。
2. 算法偏见反思，破除技术标准化桎梏：通用文本分类、风格识别算法会强制将多元、模糊、兼具多重内涵的人文文本标准化、标签化，例如将兼具写实与浪漫的古典诗词单一归类、将复杂的历史人物评价简单量化。人文学者通过伦理批判，指出算法“非黑即白”的逻辑缺陷，优化模型评价体系，保留人文文本的模糊性、多义性，避免技术简化人文、消解人文的多元价值。
3. 模型可解释性研究，守住学术严谨性：大模型、深度学习算法在人文研究中存在“黑箱问题”，机器得出的文本关联、主题演变、风格溯源结论，无法给出清晰的学术逻辑支撑。传统人文研究讲究“有据可考、有理可依”，而人文反思视角倒逼研究摒弃“唯结果论”，探索可解释性人文计算模型，让量化结论能够对应文献依据、学术逻辑，实现技术结果与人文考据的双向印证。
4. 数字遗产伦理保护：在文物图像识别、古籍数字化、口述资料采集过程中，技术往往追求全覆盖、可商用，容易出现文物影像滥用、口述隐私泄露、古籍资源商业化等问题。人文伦理视角的介入，为数据采集、算法应用、资源共享划定边界，实现技术应用与人文遗产保护、隐私保护、文化尊重的平衡。
核心总结：双向改造的融合本质
数据科学与数字人文的相遇，绝非技术对人文学的吞并替代，也不是人文学对现代计算技术的被动接纳，而是双向赋能、互相改造、彼此成就的共生关系。方法下沉实现技术落地，解决人文研究效率瓶颈；问题牵引实现技术迭代，适配人文专属场景；反思升维实现价值兜底，守住人文研究的核心底色。三者层层递进，共同构筑起“数据科学×数字人文”的全新交叉研究领域。

1. **可复现**：所有代码在统一预部署环境中一键运行；数据、环境、步骤公开，别人能重跑出同样结果。可复现，是学术诚信的底线。
2. **案例真实**：所用数据集与文献均来自真实来源（含各模块末 V2.1 国际文献与 V2.2 中文核心期刊），不拿玩具数据粉饰结论。

### 1.5 伦理坐标

如果本模块只让你带走一样东西，我们希望是**一套伦理坐标**。在数据科学的流水线上，"采集→清洗→建模→验证→沟通"每一步都可能踩线。请把它当成你的随身 checklist：

<img width="2444" height="714" alt="局部截取_20260923_162643" src="https://github.com/user-attachments/assets/704c3a11-057f-45b1-870c-9878c61da9a4" />

- **代表性**：被算进去的是谁，被悄悄遗漏的又是谁？少数族群、边缘社群的数据缺失，会让"全局结论"天然偏斜。
- **隐私与同意**：人文对象常牵涉真实个人与活着的社群——口述史受访者、家谱中的在世亲属、地方信仰的持有者。未经授权不采集、不公开。
- **文化语境**：分类与标签不是中立的。用今天的尺度去切分历史身份、用单一语言覆盖多语文本，都可能构成"分类的暴力"。
- **署名与劳动**：大量标注、转录、知识整理由社群成员与标注者完成，他们的劳动应在成果中被看见、被致谢。
- **可解释与可追责**：黑箱模型不能直接充当人文结论的依据；你能向一位历史学者说清"为什么得出这个结论"吗？

> **一条红线**：不替任何社群"代言"。凡涉在世社群或敏感文化事项，先获授权、再谈发表；拿不准时，停下来问，而不是先跑模型。

> **引子（贯穿全书的一条暗线）**：你也许觉得"数据造假"离人文学科很远。2026 年，一位科普博主用最朴素的数据审计——检查论文原始数值的分布是否符合真实实验应有的随机性——连续质疑多篇发表于《自然》(Nature) 及其子刊的论文，最终推动涉事高校通报、期刊撤稿与基金管理部门处理。方法并不神秘：**真实的数据不会"完美到诡异"**。这条暗线会在模块三（可复现即学术诚信）与模块十一（AI 时代的新造假与新打假）两次展开。

  ### 课堂练习2：复现一张“可被检验”的图表
- **目标**：把一篇开放获取论文里的一张统计图表，用你自己的工具重新画一遍，核对数据是否对得上。
- **步骤**：
  1. 选一篇开放获取的图情档中文论文，找一张柱状图或折线图；
  2. 用电子表格（或 pandas）手工录入图中读数；
  3. 用同一份数据重画该图；
  4. 对比原图与你画的图，列出至少 3 处可能出入；
  5. 写 100 字说明“如果数据对不上，问题可能出在哪”。
- **工具**：Excel / WPS，或 pandas + matplotlib。
- **产出**：一张重绘图 + 一段核对笔记。
- **评价量规**：数据录入准确（40%）、图表可复现（30%）、核对反思到位（30%）。

**课堂复现（检索即方法）**：下列代码直接调用 OpenAlex 免费 API 复现本模块文献检索（无需密钥）。

```python
import urllib.request, urllib.parse, json
q = 'data science digital humanities'
url = 'https://api.openalex.org/works?search=' + urllib.parse.quote(q) + '&per_page=10&sort=cited_by_count:desc'
oa = json.loads(urllib.request.urlopen(url, timeout=30).read())
for w in oa['results']:
    print(w['publication_year'], w['title'], '->', (w.get('primary_location') or {}).get('source', {}).get('display_name'))
```

**误用警示**：① arXiv 预印本未经同行评审，引用须标 preprint 并追正式版；② 被引数代表影响力非结论正确；③ 商业库（WoS/Scopus/Elsevier/JSTOR/CNKI）本环境无订阅，需机构账号获取后再并入。
