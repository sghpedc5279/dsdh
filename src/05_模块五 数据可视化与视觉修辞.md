## 模块五　数据可视化与视觉修辞






> **学习目标**：完成本模块后，你应能（1）区分描述性图表与叙事性可视化；（2）说出视觉修辞的三要素（路径/视角/色彩）；（3）用 pandas/matplotlib 画一张"有标注、可解释"的人文图；（4）识别至少三种常见的可视化误导手法。

### 5.1 图从来不是中立的

一张图选了什么、省略了什么、用什么尺度，都在替观众做判断。人文图表尤其要警惕：把千年的变迁画成一条平滑上升线，本身就在讲述一个"进步叙事"。可视化是**论证**，不是装饰。

### 5.2 基础图表：折线、柱状、地图、网络

- **折线**：随时间的变化（某灾害年表）；
- **柱状**：类别间的比较（各书院藏书量）；
- **地图**：空间分布（模块七详述）；
- **网络**：关系结构（模块六详述）。

pandas 一行 `df.plot()` 即可出图，但"出图"离"说清"还差一步——标注与修辞。

### 5.3 叙事可视化与 framing

Narrative Visualization（叙事可视化）把图表组织成"有顺序、有重点"的故事（见本模块 V2.1 的 *Visualization Rhetoric: Framing Effects in Narrative Visualization*）。**framing（框定）** 决定观众先看什么：先放总体趋势再钻细节，和先抛异常再回溯，结论感完全不同。

### 5.4 视觉修辞三要素：路径、视角、色彩

- **路径（Path）**：用滚动、高亮、注释引导视线顺序；
- **视角（Pathos）**：用隐喻与情绪打动人（如用"伤痕地图"呈现战争）；
- **色彩（色彩即立场）**：红=危险？暖=古老？色板本身带文化预设（见 V2.1 的 *Untangling Rhetoric, Pathos, and Aesthetics in Data Visualization*、*Data Visualization as Cultural Rhetoric*）。

### 5.5 人文图表的设计准则

- **留白**：别把图塞满，给"读"留呼吸；
- **标注**：关键拐点写一句"这里发生了什么"，而非只给坐标轴；
- **呈现不确定性**：估算区间用阴影而非单线，诚实比好看重要。

### 5.6 伦理坐标：误导与操控的红线（本模块核心能力）

- **截断轴**：纵轴不从 0 起，小差异被放大成"巨变"；
- **双轴陷阱**：两个量纲不同的序列共用一张图，强行制造"相关性"；
- **因果暗示**：相关被画成因果，时间先后被说成因果；
- **选择性呈现**：只画支持结论的年份/群体。

> **一条红线**：不为"让结论更震撼"而改动坐标轴、省略不利数据或暗示因果。图是论证，造假图等于造假论证。

### 5.7 第一次动手：画一张"有标注"的图

> **小练习 5.1（视觉修辞）**：用模块三清洗好的 CSV，画一张折线或柱状图，要求：① 纵轴从 0 起；② 至少一个拐点配一句文字标注；③ 用色彩区分两组但说明色板含义；④ 在图下写一段"我想让观众先看到什么"。本模块 V2.2 的《事件驱动的数据可视化交互设计：基于"数据叙事"的探索和实践》提供"数据叙事"的设计思路，可对照检查你的叙事顺序是否合理。


### 5.8 第二次动手：用同一数据画“两张相反的图”
- **目标**：体会可视化的 framing——同一份数据，换坐标轴 / 口径能讲相反故事。
- **步骤**：
  1. 取一份含对比的数据（如各省档案开放数量）；
  2. 画 A 图突出“差距在拉大”；
  3. 画 B 图突出“整体在提升”；
  4. 标出你各自改了哪三个视觉参数；
  5. 写反思：哪种更诚实。
- **工具**：matplotlib 或任意绘图工具。
- **产出**：A、B 两图 + 参数清单 + 反思。
- **评价量规**：两图可运行（30%）、参数标注清楚（30%）、伦理反思到位（40%）。
### 5.9 本章小结

带走三件事：**图非中立**（可视化是论证）、**修辞三要素**（路径/视角/色彩）、**误导红线**（截断轴/双轴/因果暗示/选择性呈现）。好的人文图表，让人"看见"也让人"质疑"。

### 5.10 思考题

1. 找一张你领域里"看似专业"的图，用 5.6 的红线检查它有没有误导手法？
2. "色彩即立场"——如果你用红色表示"衰落"、绿色表示"兴盛"，这背后藏着什么价值观预设？
3. 叙事可视化引导视线，会不会剥夺观众自己发现的能力？如何在"引导"与"留白"间平衡？



### 5.11 思政融入（课程思政）

> **思政融入（课程思政）**：可视化是“讲好中国故事”的有力语言。一张诚实而克制的历史图表，能让世界看见真实的中国变迁；反之，被操控的图会扭曲认知。你笔下的每一幅图，都关乎**中国叙事的真实性**——用可视化的力量呈现中华文明的连续与包容，拒绝误导与偏见。

> **思政案例（课程思政示范案例 / AI 思政课 知识库）**：可参照“人工智能赋能大思政课”（宫长瑞）“内容为王，技术为用”的原则——图首先要真实、有立场，技术只是呈现的工具。

import urllib.request, urllib.parse, json
